# 文件管理系统

本地文件浏览、预览与批量操作工具，基于 Node.js + Express。

## 功能

### 文件浏览

- 左侧目录树按需加载文件结构，展开文件夹时再读取下一层
- 支持自定义根目录路径（自动记忆）
- 首次空白页显示“知行合一”牌匾；点击顶部“大明帝国”可再次打开，牌匾点击会显示与界面主题一致的火花和随机主题词

### 统计概览

- 右上角“统计”按钮对当前管理目录执行只读扫描，支持进度显示、取消和重新统计
- “正常记录 / 备份文件夹 / 撤回文件夹”分为三个独立视图，点击标签切换；每个视图只显示本模块的文件、剧集和音频统计
- 统计名称包含“第N集”的文件夹，以及文件名包含“第N集”的 `.doc` / `.docx` 文档
- 音频按实际文件名规则分为“正文音频 / 正常返场 / 撤回返场”：含“第N集”为正文；其余不含“撤回”的音频按正常返场统计，含“撤回”的按撤回返场统计；饼图和数量条形图同时显示占比与数量
- 自动忽略程序目录、`node_modules`、`操作日志`、隐藏项、Word 临时文件和目录联接；无法读取的路径会在页面中列出

### 文件预览

- **Word (.docx)** — 原样视图 + 阅读视图，支持目录导航和内容搜索定位
- **Excel (.xlsx/.xls)** — 原样视图 + 阅读视图，支持工作表切换、列筛选和关键词筛选
- **音频 (.mp3/.wav/.m4a/.aac/.flac/.ogg/.wma)** — 显示时长、修改日期、大小和类型，使用浏览器原生控件播放并支持 0.5×–2.0× 倍速；浏览器不支持的格式会明确提示
- **文本/日志** — 语法高亮，日志搜索
- **图片** — 直接预览
- 大文件超过浏览器预览上限时会停止加载并提示使用本地软件；Word 文件还会检查解压后总大小

### 批量操作

- **整理撤回音频** — 将文件名包含"撤回"的音频移动到撤回文件夹，完成后可一键撤回
- **处理撤回文档** — 扫描 Word 文档中同时包含"返场故事"和"撤回"的段落，选择后删除该段及后续内容，原文件自动备份

所有批量操作都会先扫描再确认，支持全选、取消全选、取消扫描和实时进度。关闭扫描弹窗也会停止扫描。扫描结果包含 SHA-256 内容摘要，文件内容在扫描后发生变化时会自动跳过；结果统一显示成功、跳过、失败数量及异常原因。

会改变文件的操作遵循“先记录恢复信息，再修改文件”。恢复 Word 文档前的当前版本也会成为可恢复任务；同一恢复任务不能被多个窗口同时执行，文件任务进行中也不会被停止脚本强制中断。

### 操作日志

- 每次批量操作自动记录日志
- 按日期分文件存储，可视化查看

## 快捷键

| 快捷键 | 功能 |
| -------- | ------ |
| `Ctrl+F` | 聚焦 Word 搜索框 |
| `Esc` | 关闭个性化遮罩 / 弹窗 / 取消确认 |
| `Enter` | Word 搜索框内回车执行搜索 |

## 技术栈

- **后端** — Node.js, Express
- **前端** — 原生 HTML/CSS/JS，单文件
- **依赖** — mammoth (Word解析), jszip (docx操作), xlsx (Excel解析，已知存在高危漏洞，按使用需求保留)

## 启动（开发环境）

需要本机已安装 Node.js。

```bash
# 1. 安装依赖
npm install

# 2. 启动服务
npm start                  # 启动并自动打开浏览器
start.bat                  # 双击启动
启动文件管理系统.vbs         # 双击静默启动

# 3. 停止服务
npm run stop
停止文件管理系统.vbs
```

启动后会等待本地服务就绪，再自动打开浏览器访问实际地址（默认 `http://127.0.0.1:3000`）。如果默认端口被占用，系统会尝试后续端口；连续双击启动脚本也只会保留一个启动流程。默认管理程序文件夹上级目录的文件。

## 打包发布（免安装便携版）

打包后生成一个完全独立的文件夹，包含内置的 Node.js 运行时，用户无需安装任何软件。

### 打包步骤

```bash
# 在 build 目录下运行（或双击 build.cmd）
node build/build-portable.js
```

打包过程会**自动处理**以下步骤：

1. 校验或下载便携版 Node.js（约 30MB，需联网，仅首次；残缺缓存会自动重新下载）
2. 解压 Node.js 到 `runtime/` 目录
3. 复制项目文件（server.js、index.html 等）
4. 用内置 npm ci 安装生产依赖
5. 生成启动脚本和使用说明
6. 自动运行核心回归测试，并检查源码、便携目录、VBS、启动诊断和 ZIP 内容

打包输出在 `dist/file-manager/` 目录，同时自动生成 `dist/大明帝国文件管理.zip`，可直接发送给使用者。

### 打包产物结构

```text
dist/file-manager/
├── runtime/           # 内置 Node.js 运行时（免安装）
├── node_modules/      # 生产依赖
├── server.js          # 后端服务
├── index.html         # 前端页面
├── package.json       # 依赖配置
├── 启动文件管理系统.vbs  # 用户启动入口（无黑窗）
├── 停止文件管理系统.vbs  # 停止当前程序
├── launcher.js           # 启动协调器
├── stop.js               # 安全停止器
├── start.bat              # 兼容启动入口
└── 使用说明.txt          # 使用说明
```

## 用户使用（免安装便携版）

1. 收到 `大明帝国文件管理.zip` 后解压
2. 将程序文件夹放到要管理的目录中（系统会自动管理其**上级目录**的文件）
3. 双击 `启动文件管理系统.vbs`，浏览器自动打开
4. 使用结束后双击 `停止文件管理系统.vbs`

> **无需安装 Node.js，无需联网，解压即用。批量修改会自动备份，并可从结果或日志页面恢复。**

启动入口会直接提示缺少 `launcher.js` 或 `runtime/node.exe`；服务启动失败时还会生成 `启动错误.log` 和 `诊断信息.txt`，其中包含缺失文件、离线依赖、内置运行时和目录写入权限的检查结果。

## 开发检查

`npm run check` 会依次检查 JS/VBS 语法并运行长期保留的核心回归测试。测试覆盖统计分类、音频整理与撤回、Word 修改与恢复、过期扫描结果拦截、替换失败保留原文件、停止状态竞态、Excel 预览和打包并发锁。

> 风险说明：为满足本地 Excel 预览需求，项目明确保留 `xlsx 0.18.5`。该版本存在 npm 已公开的高危漏洞且目前没有可直接升级的修复版本，请只预览可信来源的表格文件。
